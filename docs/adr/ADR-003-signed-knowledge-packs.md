# ADR-003: knowledge pack امضاشده

- Status: accepted
- Date: 2026-10-12

## Decision

Blog و release notes در pipeline جدا به concept، claim و rule pack تبدیل می‌شوند. افزونه فقط pack امضاشده را دریافت می‌کند؛ محتوای خام خارجی در runtime اجرا نمی‌شود.

## Consequences

review انسانی، fixture مثبت/منفی، hash، signature، compatibility و rollback لازم است.
